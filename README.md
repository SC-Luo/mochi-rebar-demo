# 麻糬鋼筋算量 — AutoCAD 原生解析工作台 (Web Demo)

本展示專案展示如何只讀取建築師交付之 AutoCAD 原始二進位 DWG 圖檔，直接抽取 RC 鋼筋幾何、圖塊屬性與文字標註，並輸出具備公式與 100% AutoCAD Handle 來源追溯的 Excel 算量活頁簿。

## 核心展示功能
1. **多案切換**：
   - **友愛街 3F梁版往上**：515 筆明細，20,922.40 kg，揭盲對帳版。
   - **131210C 梁配筋全棟**：421 筆明細，16,847.27 kg，全新盲測直出版。
2. **工程啟發式規則調校**：即時動態連動重算總重量。
3. **AutoCAD 原生 Handle 身分證追溯**：支援 `_HANDENT` 指令 3 秒直達原始圖元。
4. **可追溯 Excel 下載**：內含 `=G*H*I/100` 動態公式與 DWG Handle。
